# Changelog

## [1.2.0] - 2026-10-03 (Minecraft 1.21.1)

### Added
- First release for Minecraft 1.21.1 on NeoForge, for Applied Energistics 2 19.2+.
- All 5 counters: Crafting, Processing, Smithing, Stonecutting and Fluid.
- New screen textures: a dark display with a colored icon for each counter type.
- Bigger count, drawn under the icon. Long texts shrink to fit the screen.
- New mod icon.
